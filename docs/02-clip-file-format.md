# 02 · The `.clip` file format (CLIP STUDIO FORMAT)

The format reference now lives with the library that implements it:
[`libclip/docs/FORMAT.md`](../libclip/docs/FORMAT.md).

It covers the container and chunk layout, the SQLite schema and object
graph, the tile and checksum encoding, the rules Clip Studio Paint enforces
on load (§6), pitfalls for implementers and open questions. Section numbers
are unchanged, so references such as "doc 02 §6" still apply.
